# 🚀 IoT Lab 28 - Smart Environment Control System

โปรเจกต์นี้คือระบบ IoT เต็มรูปแบบที่ประกอบไปด้วย **Sensor Node (ESP32)** สำหรับวัดอุณหภูมิและความชื้น, **Gateway (Raspberry Pi)** สำหรับประมวลผลและเก็บข้อมูลลงฐานข้อมูล, และ **Web Dashboard (React)** สำหรับแสดงผลและควบคุมพัดลมแบบ Real-time

---

## 📂 โครงสร้างโปรเจกต์ (Project Structure)

- `Final_IoT_Project/` - โค้ดสำหรับฝั่ง Hardware และ Backend
  - `esphome_sensor.yaml` - โค้ดสำหรับบอร์ดเซ็นเซอร์ (ESP32)
  - `esphome_actuator.yaml` - โค้ดสำหรับบอร์ดควบคุมพัดลม (ESP32)
  - `gateway.py` - สมองกลหลักที่รันบน Raspberry Pi
  - `database.py` - สคริปต์สร้างฐานข้อมูล SQLite
  - `setup_raspberry_pi.sh` - สคริปต์ติดตั้งระบบทั้งหมดบน Pi ในคลิกเดียว
- `iot-dashboard/` - โค้ดหน้าเว็บสำหรับแสดงผล (React + Vite + Tailwind v4 + Recharts)

---

## 🛠️ สิ่งที่ต้องเตรียมก่อนใช้งาน (Prerequisites)

1. **โปรแกรมสำหรับคอมพิวเตอร์ของคุณ (PC/Laptop):**
   - [Node.js](https://nodejs.org/) (เวอร์ชั่น 18 หรือใหม่กว่า) - สำหรับติดตั้งและรันหน้าเว็บ
   - [ESPHome](https://esphome.io/) หรือใช้ผ่านหน้าเว็บเบราว์เซอร์ - สำหรับแฟลชโค้ดลง ESP32
2. **อุปกรณ์ Hardware:**
   - บอร์ด ESP32 จำนวน 2 ตัว
   - เซ็นเซอร์ DHT22 (วัดอุณหภูมิ/ความชื้น) และ LDR (วัดแสง)
   - โมดูล Relay และพัดลม 5V
   - บอร์ด Raspberry Pi พร้อมการเชื่อมต่อ Wi-Fi (วงแลนเดียวกันกับ ESP32)

---

## ⚙️ วิธีการติดตั้งและใช้งาน (Step-by-Step Guide)

### ขั้นตอนที่ 1: ตั้งค่ารหัสผ่านความลับ (Secrets)

โปรเจกต์นี้ใช้ระบบรักษาความปลอดภัย ห้ามนำรหัสผ่านจริงขึ้นอวดบน GitHub เด็ดขาด!

1. เข้าไปที่โฟลเดอร์ `Final_IoT_Project/`
2. คัดลอกไฟล์ `secrets.yaml.example` แล้วเปลี่ยนชื่อเป็น `secrets.yaml`
3. คัดลอกไฟล์ `.env.example` แล้วเปลี่ยนชื่อเป็น `.env`
4. เปิดไฟล์ทั้งสองขึ้นมา แล้วกรอก **ชื่อ Wi-Fi** และ **รหัสผ่าน** ของห้องแล็บหรือสถานที่จริงลงไป

### ขั้นตอนที่ 2: อัปโหลดโค้ดลงบอร์ด ESP32 (Hardware Wiring)

1. นำเซ็นเซอร์ DHT22 (เข้าขา `GPIO 4`) และ LDR (เข้าขา `GPIO 34`) เสียบเข้าบอร์ดตัวที่ 1
2. นำไฟล์ `esphome_sensor.yaml` ไปแฟลชลงบอร์ดตัวที่ 1
3. นำสายสัญญาณ Relay (เข้าขา `GPIO 5`) เสียบเข้าบอร์ดตัวที่ 2
4. นำไฟล์ `esphome_actuator.yaml` ไปแฟลชลงบอร์ดตัวที่ 2

### ขั้นตอนที่ 3: ตั้งค่า Raspberry Pi (สมองกลส่วนกลาง)

1. นำโฟลเดอร์ `Final_IoT_Project` ไปวางไว้ในเครื่อง Raspberry Pi (หรือใช้คำสั่ง `git clone` ดึงโค้ดลงมา)
2. เปิดโปรแกรม Terminal ใน Raspberry Pi แล้วพิมพ์คำสั่งต่อไปนี้:
   ```bash
   cd Final_IoT_Project
   chmod +x setup_raspberry_pi.sh
   sudo ./setup_raspberry_pi.sh
   ```
3. รอสคริปต์รันประมาณ 2 นาที สคริปต์จะทำการติดตั้ง MQTT Broker, สร้างฐานข้อมูล SQLite, และตั้งค่าให้ระบบทำงานเองอัตโนมัติ (Auto-start) ทุกครั้งที่เปิดเครื่อง Pi!

### ขั้นตอนที่ 4: เปิดหน้าเว็บควบคุม (Web Dashboard)

คุณสามารถรันเว็บในเครื่องคอมพิวเตอร์ของคุณเอง หรือดูผ่านลิงก์ GitHub Pages ก็ได้

1. เปิด Terminal ในคอมพิวเตอร์ เข้าไปที่โฟลเดอร์ `iot-dashboard`
2. ติดตั้งแพ็กเกจด้วยคำสั่ง:
   ```bash
   npm install
   ```
3. รันเปิดหน้าเว็บจำลอง:
   ```bash
   npm run dev
   ```
4. **💡 ลูกเล่นพิเศษสำหรับ GitHub Pages:** หากคุณ Deploy เว็บขึ้น GitHub Pages เว็บจะมีหน้าต่างเด้งขึ้นมาถามหา **IP ของ Raspberry Pi** ทันทีที่คุณเปิดเว็บ ให้กรอกตัวเลข IP ลงไป หน้าเว็บที่อยู่บนอเมริกาจะสามารถเชื่อมต่อกับอุปกรณ์จริงบนโต๊ะของคุณได้ทันทีแบบมหัศจรรย์!

## 🧠 สถาปัตยกรรมการทำงาน (How it works)

1. **ESP32** จะอ่านค่าจากเซ็นเซอร์แล้วส่งข้อมูลไปยัง **MQTT Broker (Mosquitto)** ที่อยู่บน Raspberry Pi ผ่าน Wi-Fi
2. **Python Gateway** บน Raspberry Pi จะคอยดักจับข้อมูล นำไปบันทึกลง **SQLite** และตัดสินใจสั่งเปิด/ปิดพัดลมแบบอัตโนมัติ (Hysteresis Control)
3. **React Web Dashboard** จะเชื่อมต่อตรงไปหา Raspberry Pi ผ่านเทคโนโลยี **WebSocket** เพื่อดึงข้อมูลมาแสดงเป็นกราฟที่อัปเดตเองแบบ Real-time และให้ผู้ใช้กดควบคุมพัดลมเองได้
